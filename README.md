# eWallet Website Automated Testing (Sanitized Version)

This repository contains an automated testing suite using **Selenium WebDriver** in Python to perform comprehensive UI and functional tests for a sample website (`https://test.com`).

> ⚠️ **Note:** The original URL (`https://test.com.np`) should be replaced with `https://yourURL.com` for the testing.
---

## 🧪 Features Tested

- ✅ Homepage structure, navigation, images, CTA buttons
- ✅ Login form, validations, and error handling
- ✅ User registration with field-level validations
- ✅ Forgot password functionality
- ✅ Cross-browser JavaScript and CSS compatibility
- 📋 Generates a detailed test report (`test_report.json`)

---

## 🛠 Technologies Used

- Python 3.x
- Selenium WebDriver
- ChromeDriver (via `webdriver-manager`)
- WebDriverWait + Expected Conditions
- JSON report generation
